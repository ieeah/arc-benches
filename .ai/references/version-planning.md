# Riferimento — ARC Benches

Da leggere insieme a `SKILL.md` quando si pianifica come i task di
`docs/2_ROADMAP.md`/`docs/3_BACKLOG.md` si distribuiscono in versioni
SemVer.

## Fonte principale

Vedi `PROJECT-PROFILE.md` nella root del repository e
`docs/VERSIONING.md`, già esistente con formato proprio.

## Specifico per version-planning

- **Aggiorna `docs/VERSIONING.md`, non ricrearlo**: il file esiste già
  con un piano previsionale delle versioni verso 1.0.0 — la skill deve
  leggerlo e aggiornarlo in coerenza con quanto già scritto, non
  proporne uno nuovo da zero.
- **Milestone GitHub reali, non solo testo**: il versionamento non è
  solo documentazione descrittiva — ogni versione pianificata deve
  corrispondere a una milestone effettiva su GitHub, e le issue coinvolte
  vanno assegnate concretamente a quella milestone (campo "Milestone"
  della issue), non solo citate nel corpo di `VERSIONING.md`.
